# Карина прокачивается

Небольшая личная RPG для реальной жизни: добавляйте задания, выполняйте их и получайте XP. Проект сделан на чистых HTML, CSS и JavaScript — без сборки, сервера и зависимостей.

## Как запустить

Самый простой способ — дважды щёлкнуть по `index.html`: приложение откроется в браузере.

Либо запустите локальный сервер из папки проекта:

```bash
python3 -m http.server 8000
```

После этого откройте [http://localhost:8000](http://localhost:8000).

Данные хранятся только в `localStorage` текущего браузера. Если очистить данные сайта или открыть приложение в другом браузере, прогресс не перенесётся.

## Файлы

- `index.html` — разметка приложения;
- `icon.svg` — векторная иконка приложения;
- `manifest.webmanifest` — метаданные для установки веб-приложения;
- `styles.css` — весь внешний вид и адаптация под телефон;
- `app.js` — задания, XP, уровни, серия дней и сохранение данных.
