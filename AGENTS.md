# Карина прокачивается — инструкции для Codex

Это личное RPG-приложение Карины.

## Главные правила

- Не сбрасывать и не удалять пользовательский прогресс без прямого указания.
- Сохранять обратную совместимость с существующим localStorage.
- Основной ключ localStorage: `karina-level-up-v1`.
- Не ломать импорт и экспорт резервных копий.
- При изменении структуры данных использовать безопасную миграцию.
- Не менять механику XP, уровней, привычек и квестов, если задача этого явно не требует.

## Задания

Есть два основных типа заданий.

### Привычка

- Повторяется ежедневно.
- XP можно получить только один раз в день.
- На следующий день снова становится доступной.

### Квест

- Одноразовое задание.
- После выполнения попадает в историю.
- Автоматически не возвращается.

## Дизайн

Основной стиль приложения:

- светлый ботанический;
- молочный и тёплый белый фон;
- шалфейные и оливковые оттенки;
- песочные и природные акценты;
- тонкие веточки и листья;
- женственно, современно, минималистично;
- не делать детским или слишком декоративным;
- избегать фиолетового и неоновых цветов.

## Mobile

Приложение в основном используется на iPhone.

При изменениях интерфейса:

- обязательно проверять ширины 375px и 430px;
- не допускать горизонтального скролла;
- кнопки и элементы управления должны нормально работать на iOS Safari;
- учитывать использование приложения с экрана «Домой».

## GitHub Pages

Проект публикуется через GitHub Pages.

Все пути должны работать при размещении приложения в подпапке репозитория.

## Файлы

По возможности использовать текстовые форматы.

Не создавать бинарные PNG/ICO в задачах Codex, если это мешает созданию PR.

## Перед завершением задачи

Проверить:

- приложение запускается;
- существующие данные пользователя не потеряны;
- резервные копии работают;
- мобильная версия не сломана;
- изменения ограничены текущей задачей.

Не добавлять дополнительные функции, которых пользователь не просил.
